# Retail Data Analysis Project

## Project Overview
This project performs Exploratory Data Analysis (EDA) on a retail Superstore dataset to understand sales performance, profitability, regional trends, and product performance.

## Objectives
- Analyze sales across different product categories.
- Identify profitable and loss-making sub-categories.
- Compare sales performance across regions.
- Analyze monthly sales trends.
- Identify the top 10 products by sales.

## Dataset
Sample Superstore Dataset (Excel format).

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook / Python

## Visualizations
1. Sales by Category
2. Profit by Sub-Category
3. Sales by Region
4. Monthly Sales Trend
5. Top 10 Products by Sales

## Key Findings
- Copiers generate the highest profit among sub-categories.
- Tables show the biggest loss.
- Sales performance varies across product categories and regions.
